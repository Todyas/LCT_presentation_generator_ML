# Аудит презентаций

Аудит является частью generation pipeline: после сборки каждого варианта
система запускает детерминированные проверки PPTX/IR и контекстуальную проверку
LLM. После правки одного слайда вариант пересобирается и проверяется повторно.

Этот документ описывает фактическое состояние кода. Статус «нет» означает
осознанный пробел относительно Приложения 1 ТЗ, а не скрытую проверку.

## Архитектура

`run_full_audit` объединяет пять источников замечаний:

1. `geometry_audit` — выход за границы и пересечения по bbox компонентов;
2. `contrast_audit` — WCAG-контраст текста к вычисленному фону;
3. `density_audit` — bullets, длина bullet, размер таблиц, заглушки;
4. `visual_audit` — пустой контент и визуальная монотонность;
5. `semantic_audit` — контекстуальная LLM-проверка IR относительно brief.

Результат хранится как `AuditReport`: variant, время генерации и список
`AuditIssue` с типом, severity, индексом слайда, сообщением, shape IDs, bbox и
признаками `auto_fixable`/`fixed`.

Если LLM недоступна или вернула невалидный результат, пайплайн не падает:
создаётся INFO-issue `AUDIT_DEGRADED`. Это означает, что детерминированная часть
выполнена, а семантическая — нет.

## Реализованные issue types

| Код | Тип | Severity | Что проверяется |
|---|---|---|---|
| `COLLISION` | детерминированный | CRITICAL | пересечение bbox с небольшим допуском |
| `OVERFLOW` | детерминированный | CRITICAL | выход bbox компонента за слайд |
| `CONTRAST` | детерминированный | CRITICAL | WCAG AA: 4.5:1, для крупного текста 3:1 |
| `DENSITY_BULLETS` | детерминированный | CRITICAL | больше 6 bullets в блоке |
| `DENSITY_WORDS` | детерминированный | CRITICAL | больше 15 слов в bullet |
| `TABLE_SIZE` | детерминированный | CRITICAL | превышение лимита таблицы |
| `PLACEHOLDER_TEXT` | детерминированный | CRITICAL | `TODO`, `Lorem ipsum`, `XXX`, `заглушка`, `ТБД` |
| `EMPTY_CONTENT` | детерминированный | CRITICAL | контентный слайд без компонентов |
| `VISUAL_MONOTONY` | детерминированный | WARNING | три текстовых слайда подряд или мало типов компонентов |
| `SEMANTIC_WEAK_TITLE` | контекстуальный | WARNING | заголовок называет тему вместо вывода |
| `HALLUCINATED_NUMBER` | контекстуальный | WARNING | число не подтверждено brief |
| `LANGUAGE_MIX` | контекстуальный | WARNING | смешение языков в колоде |
| `AUDIT_DEGRADED` | служебный | INFO | semantic audit не удалось выполнить |

Дополнительно Pydantic-модели не позволяют создать IR с более чем 6 bullets,
bullet длиннее 15 слов, более чем 4 сериями диаграммы и невалидной формой
таблицы. Это pre-build validation, а не отдельные audit issues.

## Матрица требований Приложения 1

Обозначения: **да** — выполняется в pipeline; **частично** — покрыт только
близкий случай или проверяется IR вместо итогового рендера; **нет** — проверки
в текущем коде нет.

### Вёрстка

| Требование | Статус | Реализация / ограничение |
|---|---|---|
| Элемент вышел за границы слайда | да | `OVERFLOW` по bbox верхнеуровневого компонента |
| Два блока наложились | да | `COLLISION` по bbox компонентов |
| Текст не поместился в рамку | частично | builder применяет autofit, но итоговый overflow текста отдельно не измеряется |
| Текст обрезан краем слайда | частично | bbox проверяется; фактические глифы/рендер не анализируются |
| Выравнивание по направляющим | нет | guide/grid analyzer отсутствует |
| Контент заходит в поля | нет | проверяются границы слайда, но не safe margins шаблона |
| Нарушены пропорции картинки | нет | реальные image assets пока не вставляются |

### Шаблон

| Требование | Статус | Реализация / ограничение |
|---|---|---|
| Шрифт не из шаблона / больше двух гарнитур | частично | builder назначает извлечённые шрифты; независимой проверки PPTX нет |
| Кегль не из типографической шкалы | нет | autofit может уменьшать кегль вне исходной шкалы |
| Цвет не из палитры | частично | генератор использует theme colors; независимой проверки всех shapes нет |
| Layout не из шаблона | частично | слайд создаётся на layout шаблона, но отдельного audit issue нет |
| Сдвинут логотип/колонтитул | нет | позиция template chrome не сравнивается с эталоном |
| Контраст ниже 4.5:1 | да | `CONTRAST`; для крупного текста применяется WCAG-порог 3:1 |

### Плотность

| Требование | Статус | Реализация / ограничение |
|---|---|---|
| Больше 6 bullets | да | схема IR и `DENSITY_BULLETS` |
| Bullet длиннее 15 слов | да | схема IR и `DENSITY_WORDS` |
| Таблица больше 7 строк или 5 колонок | частично | проверка есть, но текущие константы ошибочно задают 5 строк и 7 колонок |
| Больше 5 серий диаграммы | да | IR разрешает максимум 4 серии, то есть строже ТЗ |
| Заполнение меньше 25% или больше 75% | нет | area/density analyzer отсутствует |

### Целостность

| Требование | Статус | Реализация / ограничение |
|---|---|---|
| Файл не открывается | частично | builder сохраняет через `python-pptx`, тесты переоткрывают файлы; runtime issue нет |
| Остался текст-заглушка | да | `PLACEHOLDER_TEXT`; список не включает фразу «вставьте текст» |
| Пустой слайд / только заголовок | да | `EMPTY_CONTENT`, кроме cover/section layouts |
| Слайд является одной картинкой | частично | builder создаёт native objects; отдельной post-build проверки нет |
| У диаграммы нет осей, единиц или легенды | нет | chart completeness audit отсутствует |
| Дублирующиеся слайды | частично | outline проверяет похожие key messages до сборки; audit готовой колоды не проверяет |

### Валидация контента

| Вопрос ТЗ | Статус | Реализация / ограничение |
|---|---|---|
| Заголовок содержит вывод | да | `SEMANTIC_WEAK_TITLE` |
| Содержимое соответствует заголовку | нет | semantic skill этого не проверяет |
| Слайд пересказывается одним предложением | нет | отдельного критерия нет |
| Все цифры и факты есть в источниках | частично | числа проверяются; произвольные факты и content pack — нет |
| Есть содержание, а не только заголовок | да | `EMPTY_CONTENT` |
| Картинки и иконки относятся к теме | нет | VLM-аудит PNG отсутствует |
| Нет служебного мусора | частично | известные placeholders проверяются, prompt fragments/notes — нет |
| Текст без опечаток | нет | spellchecker отсутствует |
| Вся колода на одном языке | да | `LANGUAGE_MIX` через LLM |
| Строки таблицы и легенда работают на мысль | нет | контекстуальная проверка отсутствует |
| Соседние слайды логически связаны | нет | coherence audit отсутствует |

## Визуализация и исправление

Backend возвращает issues и для geometry issues формирует нормализованный bbox
в `/jobs/{job_id}/result`. Endpoint `/jobs/{job_id}/audit/{variant}` возвращает
полный `AuditReport`. Пользователь может пересобрать выбранный слайд с
инструкциями и получить новый audit.

Текущее ограничение: frontend-нормализатор не сохраняет `slide_index`,
`issue_type`, bbox и score из фактического API-контракта. Поэтому overlay и
надёжная привязка замечания к слайду пока не работают, а выбор конкретного
issue для исправления не реализован. Наличие bbox в backend нельзя считать
готовой пользовательской визуализацией.
